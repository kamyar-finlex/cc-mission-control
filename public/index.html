Send replies straight to the agent

The Claude app has no way for other programs to type into a session, so the console does it the way you would: it opens the session, pastes your reply, checks the message box really contains it, and presses Enter. If any check fails it stops before Enter and leaves your reply on the clipboard.

  1. Open System Settings → Privacy & Security → Accessibility.
  2. Click +, press ⌘⇧G, paste this path, and press Enter:
  3. Turn the switch for node on.
  4. On the first send, macOS asks whether node may control System Events: choose Allow. (Changed your mind later? Privacy & Security → Automation.)

Use it only while you're at the keyboard; don't click elsewhere during the second or two it takes.
